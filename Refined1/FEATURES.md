# Refined1 功能清单

本文档描述 Refined1 当前已经提供的全部用户功能、技术接口和已知限制。

> **维护规则：** 每次新增、修改或移除功能时，必须在同一次变更中更新本文档，对应调整功能状态、使用说明、依赖条件和已知限制。未同步更新本功能清单的功能变更不视为完成。

## 产品流程

```text
选择操作界面
  → 上传或加载平面图
  → 自动识别墙体、门窗和房间
  → 标定比例并修正二维结构
  → 确认房间名称、用途和面积
  → 选择智能布置方案或手动添加内饰
  → 添加灯光
  → 三维预览、漫游和渲染
  → 保存项目或导出 JSON
```

- 墙体阈值。
- 最短墙线。
- 合并间距。
- 最大墙厚。

## 16. 当前已知限制

- 房间多边形目前面向水平、垂直的正交墙网；L 型和凹型空间已支持，斜墙、弧形墙以及带内孔的复杂空间仍需后续扩展。
- 门窗临时桥接依赖洞口已被识别为门、窗或普通开口；仍标记为“不确定”的候选不会参与封闭，避免错误切分房间。
- 房间用途使用规则推测，需要用户人工确认，不应视为最终建筑语义结论。
- 门窗自动识别属于基础版，真实扫描件、低清图和复杂符号仍可能需要手动修正。
- 实际面积依赖正确的比例标定。
- 资产目录虽然包含 21 个分类，但真实 GLB 模型需要自行放入目录或手动导入。
- 内饰碰撞体目前只支持盒形碰撞箱。
- 线光源由多个点光源近似模拟，并非独立的物理面光源。
- 浏览器语音识别取决于浏览器实现、权限和可用的语音服务。
- 当前为单机本地原型，不包含账号、云端同步、多人协作或报价清单；智能布置是本地规则版，不是生成式 AI 方案。
- 尚未完成真实图纸数据集上的系统性准确率、性能和回归基准测试。

## 17. 推荐演示顺序

1. 进入详细界面并加载样例。
2. 查看叠加识别结果和识别统计。
3. 标定一条已知尺寸，确认房间面积更新。
4. 点击“编辑房间”，修改名称和用途。
5. 点击“房间信息：开/关”，观察二维和三维标签联动。
6. 手动画墙、门窗或栏杆，并演示撤销、复制和粘贴。
7. 打开“智能布置”，依次演示基础、出租房和家庭居住方案。
8. 从内饰资源库手动添加占位件，证明自动替换不会删除手动家具。
9. 演示移动、旋转、缩放以及墙体、门窗和家具碰撞阻止。
10. 添加点光或线光，调整色温、亮度和阴影。
11. 切换到三维漫游并生成高清渲染图。
12. 保存项目，再重新打开验证完整恢复。
13. 导出 JSON，展示墙体、房间、自动产品来源和灯光数据。
