# 测试文件

- `sample-floor-plan.svg`：可上传或通过页面“加载样例”按钮使用的测试平面图。
- `test_room_information.py`：房间面积、每面墙长度、用途推测、编辑、显示开关与项目持久化契约测试。
- `test_room_polygons.py`：门窗洞口临时桥接、封闭空间多边形、非标准矩形边界和智能布置边界契约测试。
- `test_auto_layout.py`：三种智能布置方案、房间模板、门窗安全区、碰撞复用和自动结果替换契约测试。
- `test_quantity_report.py`：地面、吊顶、墙面、踢脚线、构件分类汇总、计算追溯、高亮和 CSV/JSON 工程量导出契约测试。
